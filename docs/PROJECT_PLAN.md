# 当前项目计划

最后更新：2026-08-26

## 当前阶段

首个参与者纵向里程碑已经实现并通过本地验收。当前代码包含活动届次、身份保护、版本化题库、抽题、服务端计时、幂等提交、分类最高分、题库管理命令、参与者 JSON 接口和正式参与者网页。SQLite 快测、真实旧库导入、PostgreSQL 18 的五组 50 路并发门禁和真实浏览器网络联调均已通过。

参与者原型已在独立任务确认，并整合为 Django 模板、原生 JavaScript 和正式静态资源。管理后台、部署和公开发布仍未开始。

## 已确认产品规则

- 参与者提交显示名、学号或工号，以及手机号或邮箱二选一的联系方式。
- 显示名允许使用姓名或昵称；身份资料通过 HTTPS 传输并存入受控数据库。
- 每次从一个板块随机抽取 15 题，限时 5 分钟；题量和时间可配置，服务端校时。
- 允许重复挑战。每次记录独立保存，分类最高分用于管理员内部趣味榜。
- 结果页显示本次得分、分类最高分和每题对错，不直接公布正确答案。
- 内部趣味榜按板块和分类最高分降序排列，同分共享名次，不向参与者展示。
- 管理后台使用单一管理员角色，但每人使用独立账号并记录关键操作。
- 兑奖只维护少量可复用兑奖词及其显示条件，不作为安全凭证。

## 实施顺序

1. 建立参与者、身份资料、板块、题目、答题记录、分类最高分、兑奖词和管理员操作记录模型。
2. 实现 Excel 题库导入、来源与许可字段、稳定题号和失败即停止的校验。
3. 实现服务端抽题、计时、提交、原子计分和重复答题。
4. 建立并发与回归测试，目标覆盖 30 至 50 个同时提交。
5. 实现参与者页面和管理后台监控、检索、字段展示、导出及活动控制。
6. 基于已确认的角色主视觉展架方向完成参与者页面，并进行手机与桌面浏览器验收。
7. 在私有预发布环境验收，再制作可部署发布包。
