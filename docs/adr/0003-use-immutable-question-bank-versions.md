# 使用不可变题库版本

题目内容、题图和抽题规则在一次导入后组成不可变题库版本。答题记录固定引用开始时的版本，因此现场修题不会改变已经抽出的题目或历史判分依据。

活动开放时不能直接改题。发现错题后先暂停活动，导入并校验新版本，记录操作人和原因，再切换当前版本。恢复开放后的新答题使用新版，已有答题继续使用旧版。

普通题库只有在题目来源已核实且允许私密活动使用时才能启用。`legacy-2024` 转换版本可以通过带批准人、理由和时间的旧库例外用于私密活动，但每题仍保持 `pending` 审查状态，也不得进入公开示例、Git 历史或公开素材包。
