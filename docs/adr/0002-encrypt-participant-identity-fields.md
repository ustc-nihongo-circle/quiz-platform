# 加密参与者编号和联系方式

参与者编号和联系方式既要支持同一活动届次内的再次进入，又不应以明文出现在数据库副本和备份中。系统使用环境提供的版本化 AES-256-GCM 密钥加密原值，并用另一把 HMAC-SHA256 密钥生成活动届次内的查重摘要。摘要输入包含活动届次 ID，避免同一编号在不同届次产生相同值。

显示名保留明文，用于参与者页面和内部趣味榜。它与加密身份资料保存在可删除的身份记录中。人工去身份化会删除整条身份记录，只保留内部参与者 ID、答题统计和不含身份资料的审计事实。

密钥不得进入代码、文档、镜像或发布包。密文保存 `key_id`，轮换命令只重加密原值，不改变查重摘要。
