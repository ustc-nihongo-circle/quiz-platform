# ADR 0004：使用自定义现场管理控制台

状态：已接受

## 决策

活动管理员使用 `/ops/` 自定义控制台和同一个 `quiz_operator` 权限。每人使用独立账号。生产环境不挂载 Django 默认 `/admin/`。

编号和联系方式默认脱敏。管理员可以在当前页面揭示已选记录的完整字段，无需填写原因；系统自动记录管理员、活动、字段和行数，不保存明文。身份 CSV 导出必须填写用途说明。

## 原因

Django 默认后台允许直接编辑模型，容易绕过活动状态、题库切换、作废重算和审计服务。自定义控制台把现场操作限制在已有事务服务中，也能对身份字段实施比模型级权限更细的展示规则。

## 影响

- 新建届次、题库导入和分类配额继续使用管理命令。
- 所有控制台写操作使用 POST、CSRF 和统一权限。
- 登录失败通过 django-axes 限速。
- 审计日志只能读取，控制台没有修改或删除入口。
