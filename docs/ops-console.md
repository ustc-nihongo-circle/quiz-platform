# 现场管理控制台参考

最后更新：2026-09-12

## 入口和权限

现场管理控制台位于 `/ops/`。每名管理员使用独立 Django 账号，并拥有同一个 `quiz.operate_quiz` 权限。生产配置不挂载 Django 默认 `/admin/`。

先创建账号，再单独设置密码：

```powershell
python manage.py provision_quiz_operator field-operator
python manage.py changepassword field-operator
```

登录失败按账号与客户端地址组合计数。五次失败后锁定十五分钟。成功登录会清除失败计数。管理员 Session 最长八小时，浏览器关闭后失效。

## 页面能力

活动统计位于页首，显示参与者、进行中、已提交、已超时和已作废数量。页首提供“立即刷新”和“自动刷新（30秒）”开关，显示最近成功更新时间（北京时间）。活动后台统一更新统计、当前检索结果、最近答题、当前板块榜单与审计日志；活动控制表单不被替换。个人记录页更新当前页的答题状态、得分、时间和提交记录。

刷新保留已应用的检索条件、排序、页码、勾选状态、未提交表单、滚动位置和个人记录展开状态；新出现的参与者不会自动加入已有勾选。正在输入、选取文字、执行操作或查看完整身份字段时暂缓刷新；隐藏标签页停止定时请求，返回时按开关状态更新。失败保留现有内容并显示提示，自动重试退避到60秒、120秒；单轮请求最长15秒，登录失效时停止自动请求。切换开关只在当前浏览器标签页会话保存，不存储检索条件或身份数据。

正文保留长页，按以下顺序排列：

1. 参与者检索：显示名、编号、联系方式、内部参与者 ID、排序与分页。
2. 最近答题：对应显示名、开始时间、答题状态、得分与作废入口。
3. 内部趣味榜：按板块查看成绩。
4. 数据导出：无身份统计与身份对应表。
5. 活动控制：参与者入口届次、活动状态和当前题库。
6. 审计日志。

桌面侧栏提供栏目锚点，手机使用“后台栏目”下拉框定位。切换栏目保留本页检索输入；切换活动会加载对应活动页面。网址片段支持刷新后回到相应栏目，滚动时导航同步当前位置。JavaScript 不可用时仍可使用活动和栏目链接。

兑奖词板块已移除；已有规则、答题快照及相关接口保留。本次导航调整不改变兑奖判定。

新建届次、题库导入、分类和抽题池配额仍使用管理命令。

## 参与者排序与个人记录

参与者列表默认按最近开始答题的时间从新到旧排序，未答题者排在末尾。可切换最新登记、最早登记、显示名字符顺序或答题次数从多到少。次数和最近答题时间包含所有状态，包括已作废答卷；同值使用登记时间及内部 ID 稳定排序。显示名排序使用数据库的字符排序规则，不保证拼音顺序。

排序应用于全部匹配结果，然后按每页 50 人分页。检索和翻页保留当前排序；更换排序会回到第一页并继续使用已填写的检索条件。检索字段仍以 POST 提交，不写入 URL。

“参与者检索”和“最近答题”的显示名均链接到该参与者在当前活动中的记录页，也可点击“全部答题”。同名参与者按内部 ID 区分；已去身份化记录显示“已去身份化”。

个人记录页包含全部状态的答题，按开始时间从新到旧排列，每页 25 条，可翻页查看全部历史。每条展示板块、开始/截止/交卷时间、状态和得分，展开“逐题提交记录”可看题序、实际提交内容及当次判定。页面不显示答案库或完整编号、联系方式，也不读取浏览器里尚未交卷的草稿。作废记录保留，其分数不计入有效成绩。

记录页继续要求 `quiz.operate_quiz` 权限，并按活动和参与者 ID 同时校验。查看与排序不修改活动、计分或答题状态。

## 身份字段

显示名默认完整显示。编号和联系方式默认脱敏。

“显示完整编号”和“显示完整联系方式”只处理当前页中已勾选的记录。服务器返回完整值并记录管理员、活动、字段和行数，浏览器只把值放入当前 DOM。刷新或离开页面后恢复脱敏。审计记录不保存检索条件和明文。

编号、联系方式和内部 ID 使用 POST 精确检索，不进入 URL 和代理访问日志。

## 导出

无身份统计 CSV 使用内部参与者 ID 关联答题记录和分类最高分，不含显示名、编号或联系方式。

身份对应 CSV 包含内部 ID、显示名、编号和联系方式。管理员必须填写用途说明。系统流式生成文件，不在服务器保存临时副本。所有以 `= + - @` 开头的文本会增加单引号，避免电子表格执行公式。

## 现场操作规则

- 只有显式参与者入口届次可以开放。
- 暂停和关闭会阻止新登记与新答题；已有身份仍可再次进入，已有答题仍按原截止时间提交。
- 题库只能在 draft 或 paused 状态切换。往届私密例外必须显式勾选并填写原因。
- 作废答题会保留原记录，并在同一事务内重算分类最高分。
- 去身份化会删除身份表，保留无法关联现实身份的答题统计和审计事实。

## 日志边界

控制台、应用和代理日志不得记录参与者明文身份、题干、答案、请求正文或导出内容。管理员填写原因时也不应复制身份资料。

实现与真实浏览器验收结果见 [管理控制台与 Linux 实验验收](validation-ops-lab.md)。
## 测试历史只读入口

配置独立的 `QUIZ_HISTORY_DB_NAME`、`QUIZ_HISTORY_DB_USER` 和 `QUIZ_HISTORY_DB_PASSWORD` 后，后台首页显示“查看测试历史（只读）”。登录仍使用正式后台操作员账号。

历史页支持活动列表、显示名检索、排序、分页及个人逐题提交记录。检索名称放在受 CSRF 保护的 POST 正文中，不放入 URL。历史页不提供活动开关、作废、身份揭示或导出；正式活动与历史数据分别查询，不复制测试参与者到正式库。

历史数据库连接默认只读，数据库角色也必须只授予所需查询权限；禁止迁移到 history 别名。身份表仅查询显示名和内部参与者键，不读取编号或联系方式密文。历史连接不可用时，只读入口返回503，正式后台和答题服务继续使用主数据库。
